This activity involved creating a promotional poster for a free coffee event using design principles. The output focused on attractive typography, colors, images, and proper arrangement of information.

I learned that good design helps make information easier to understand and remember. I learned how to use contrast, alignment, and visual hierarchy to make a poster eye-catching and readable. My challenge was balancing the large text with the other design elements without making the poster look too crowded. I solved this by adjusting the placement and sizes of the elements. I can use these skills to create better presentations, posters, and other visual materials.
