This activity involved using two Large Language Models to create professional resumes using the same prompt. The outputs were compared based on their structure, clarity, formatting, and overall quality.

I learned how different AI tools can generate different results even when given the same instructions. My challenge was determining which resume was more professional and easier to read. I addressed this by comparing the layout, content, and organization of both outputs. I can use this knowledge to create a better resume for future job applications while making sure the information is accurate and reflects my actual qualifications.
